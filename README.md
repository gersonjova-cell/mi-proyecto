# Luma — hábitos de sueño

Prototipo web de una app de suscripción para crear una rutina de sueño saludable,
completar objetivos diarios y acumular puntos canjeables tras 365 días.

## Ejecutar

```bash
npm run dev
```

Abre `http://localhost:4173`.

## Comprobar

```bash
npm test
```

Los datos de la demo se guardan en `localStorage`. La transferencia de la
recompensa final requiere validación y procesamiento manual fuera de la app.
